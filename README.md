### 📂 [Section 2: Cypher 기본 문법](./section2)
* 🔹 `Node` : 그래프의 핵심 개체 생성 및 조회
* 🔹 `Relationship` : 노드 간의 관계 설정 및 방향성 이해
* 🔹 `주요 구문` : `MATCH`, `CREATE`, `RETURN` 등 필수 절 마스터

### 🚀 [Section 3: Cypher 고급 문법](./section3)
* 🔹 `가변 길이 탐색` : `-[:REL*1..3]->` 패턴을 이용한 심층 추적
* 🔹 `최단 거리 탐색` : `shortestPath()` 함수를 활용한 최적 경로 탐색
* 🔹 `집계 함수` : `COUNT()`, `SUM()`, `COLLECT()` 데이터 정제
* 🔹 `WITH 절` : 쿼리 중간 결과를 다음 파이프라인으로 전달하기 (`WITH`)

### 🤖 [Section 4: Neo4j 기반 그래프 RAG 분석](./section4)
* 🔹 `기본 검색` : Cypher 쿼리를 활용한 정밀 구조 탐색
* 🔹 `전문 검색` : Full-Text Index를 활용한 텍스트 기반 노드 검색
* 🔹 `벡터 검색` : 고차원 임베딩 벡터를 활용한 유사도 분석
* 🔹 `Graph RAG` : 지식 그래프(Knowledge Graph)와 LLM의 결합 구조 이해
